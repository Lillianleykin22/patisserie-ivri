# 🍰 אתר פטיסרי | Patisserie Website

**פרויקט בפיתוח | Work in Progress**

פרויקט לבניית אתר עבור פטיסרי באמצעות HTML ו־CSS, כחלק מתהליך הלמידה שלי בפיתוח Full Stack.

A website project for a patisserie, built with HTML and CSS as part of my Full Stack development learning journey.

## 📝 על הפרויקט | About the Project

מטרת הפרויקט היא לתרגל בניית אתרים, מבנה עמודים ועיצוב באמצעות HTML ו־CSS.

The goal of this project is to practice website development, page structure, and styling using HTML and CSS.

## 🛠️ טכנולוגיות | Technologies

- HTML
- CSS

## 🚧 סטטוס הפרויקט | Project Status

האתר נמצא בתהליך פיתוח, ותכונות ועיצובים נוספים יתווספו בהמשך.

The website is currently under development, with additional features and design improvements planned.

- תרגול כתיבת HTML מובנה | Practice writing structured HTML
- שיפור מיומנויות CSS ועיצוב עמודים | Improve CSS and page styling skills
